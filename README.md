# Banking Customer & Loan Analytics

## 📌 Project Overview
This project focuses on analyzing customer and loan data to identify business insights, customer behavior, loan performance, and risk patterns.

## 🛠️ Tools & Technologies
- SQL
- Excel
- Power BI
- Python

## 🎯 Project Objectives
- Analyze customer demographics
- Identify loan trends
- Analyze loan amounts and repayment patterns
- Identify high-value customers
- Understand loan performance
- Create business-focused dashboards

## 📊 Key Analysis
- Customer segmentation
- Loan distribution analysis
- Loan amount analysis
- Customer income analysis
- Loan status analysis
- Regional analysis

## 📈 Dashboard
Power BI dashboard will be added after completing the analysis.
